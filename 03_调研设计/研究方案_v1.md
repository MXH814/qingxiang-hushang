# 研究方案 v1

## 1. 研究设计概述

采用“政策与服务审计 + 问卷 + 半结构访谈 + 实地观察 + 对照可用性测试”的混合方法。不同方法不简单叠加，而是分别回答不同问题并相互校验。

| 方法 | 主要回答 | 证据类型 |
|---|---|---|
| 政策与服务审计 | 官方信息客观上如何组织，跨平台/流程如何衔接 | 页面、事项卡、流程图、审计评分 |
| 问卷 | 哪些事项和障碍更普遍，不同人群是否有差异 | 量化分布、交叉分析 |
| 访谈 | 障碍如何发生、为什么发生、带来什么后果 | 真实经历、主题和反例 |
| 实地观察 | 线下入口、导视、材料和线上衔接是否友好 | 观察记录、影像和现场流程 |
| 对照测试 | AI导办是否比常规检索更高效、准确、可信 | 配对任务数据和用户反馈 |

## 2. 分析单位

- 用户层：一名来沪青年及其身份、阶段、经验和感受。
- 事项层：一个明确公共服务事项，如居住登记。
- 旅程层：完成一个目标所需的跨事项、跨平台、线上线下步骤。
- 界面层：一个官方页面、移动端入口、线下导视或原型回答。

区分这四个层级，避免把“页面不好找”“政策难理解”“制度条件不满足”和“用户缺乏经验”混为一谈。

## 3. 可及性框架

### 3.1 客观服务可及性

1. 可发现：能否从常见入口找到权威服务；名称是否符合用户语言。
2. 可理解：条件、术语、材料和例外是否可被非专业青年理解。
3. 可匹配：能否根据学籍、户籍、就业、租住和来沪阶段判断适用性。
4. 可行动：是否清楚说明下一步、顺序、材料、时限、地点和结果。
5. 可衔接：跨部门事项、线上线下渠道和不同平台是否同源一致。
6. 可信与包容：来源、日期、咨询/纠错渠道、移动体验和替代方式是否充分。

### 3.2 主观体验

- 自评信息寻找难度；
- 自评理解难度；
- 对资格和材料判断的信心；
- 对来源的信任；
- 预期/实际时间成本；
- 放弃、延误、重复跑动或求助经历；
- 对AI导办的接受条件与担忧。

### 3.3 结果指标

- 任务成功率；
- 完成时间；
- 条件判断准确率；
- 材料识别准确率；
- 官方来源识别率；
- 求助次数；
- 主观信心和满意度；
- 严重错误数。

## 4. 评分原则

v1阶段不强行合成一个“可及性总分”。

- 客观审计：每个二级指标采用0/1或0/1/2锚定评分，按维度标准化为0-100。
- 主观体验：使用5点量表，报告题项分布和维度平均值。
- 任务表现：单独报告成功、时间和准确率。
- 仅在题项一致性、缺失情况和权重敏感性检查后，才考虑展示总指数。
- 不对政府部门作排名；比较的是事项旅程、渠道和信息组织模式。

## 5. 样本计划

### 5.1 问卷

- 目标有效样本：100-150；最低80。
- 核心配额建议：求职/实习/初就业样本不少于有效样本的50%；来沪不满2年不少于50%；至少30人有真实安居/居住办事经历。
- 招募渠道：本校及在沪高校同学、实习群、毕业生/校友网络；记录渠道以评估便利抽样偏差。

### 5.2 访谈

- 目标10-15人，最低8人。
- 最大差异抽样：来沪阶段、时长、是否有办事经历、居住类型尽量不同。
- 至少纳入：集体宿舍/学校场景、市场租赁、求职短住/青年驿站或保租房关注者各若干。

### 5.3 实地观察

- 目标2个点，最低1个。
- 优先组合：1个社区事务受理服务中心 + 1个青年人才/就业/安居服务点或另一行政区服务中心。

### 5.4 可用性测试

- 目标10-15人，最低8人。
- 采用被试内对照：同一参与者分别完成常规检索与AI导办的等价任务。
- 平衡使用顺序，减少学习效应；任务A/B难度需经预试校准。

## 6. 数据分析预案

### 问卷

- 样本描述、事项知晓/使用率、困难率、求助渠道和结果分布。
- 按来沪阶段、来沪时长、办事经验等做探索性交叉分析。
- 量表先检查缺失、分布和内部一致性，再决定是否计算维度分数。
- 便利样本不作“代表全体来沪青年”的推断。

### 访谈与观察

- 使用演绎+归纳编码：先按六个可及性维度编码，再允许新增主题。
- 保留正面经验、反例和不同意见，避免只摘录支持预设的问题。
- 将关键主题映射到用户旅程节点和原型需求。

### 对照测试

- 配对连续指标：优先报告中位数和个体差值；满足条件时用配对t检验，否则用Wilcoxon符号秩检验。
- 配对二分类成功率：样本允许时使用McNemar检验，同时报告原始人数和比例。
- 小样本以效应方向、差值分布和错误类型为主，不以显著性作为唯一证据。

## 7. 质量控制

- 调研工具先用5-8人预试。
- 观察员培训后对同一页面/场景独立评分，讨论分歧并修订锚点。
- 原始数据只读保存，清洗步骤可复现。
- 在看结果前确定剔除规则和主要指标。
- 所有结论进入报告前完成证据追踪。
