# 半结构访谈提纲 v1

## 1. 基本设置

- 时长：15-25分钟。
- 对象：来沪求职、实习、初就业或准备毕业留沪青年。
- 记录：匿名编号；录音、照片、匿名引用分别征得同意。
- 目标：获得真实经历和机制解释，不向参与者推销原型。

## 2. 开场筛选（2分钟）

1. 您目前处于在沪学习、实习、求职、初就业还是其他阶段？
2. 来上海多久了？目前主要是什么居住方式？
3. 过去两年是否查过或办过青年驿站/保租房、租赁备案、居住登记、居住证、就业服务等？

只记录与分析需要有关的背景，不追问具体单位、地址或证件信息。

## 3. 真实经历复盘（8-12分钟）

请选择最近或最印象深刻的一次经历，从“第一次想到要办”开始讲。

追问：

- 您当时想达到什么目标？为什么在那个时间需要它？
- 第一反应是去哪里找？搜索了什么词？为什么信任那个渠道？
- 最难理解或最不确定的是什么？
- 哪些身份条件让您不知道自己是否适用？
- 材料、前置事项和办理顺序是否清楚？
- 是否在一网通办、随申办、部门页面、公众号、热线、窗口之间跳转？
- 不同渠道有没有说法不一致或信息粒度不同？您最后相信谁？
- 是否求助同学、学校、单位、房东、中介或工作人员？
- 最终是否完成？多花了什么时间或产生什么后果？
- 如果结果是“不符合条件”，此前是否能更早知道？

## 4. 安居与城市融入（3-5分钟）

- 住房和居住手续是否影响您来沪求职、实习或留下发展的决定？如何影响？
- 您是否听说过青年驿站、保租房或人才公寓？最初从哪里知道？
- 您觉得不同阶段（毕业、求职、实习、初就业）的服务是否容易衔接？
- 除安居外，哪个公共服务最影响您在上海的稳定感或归属感？

## 5. AI导办概念测试（3-5分钟）

先不展示原型，用一句中性描述：

> 我们设想一种基于官方政策来源的问答式导办：它会先询问必要情形，再给出可能适用的服务、材料、顺序、官方入口和风险提示。

追问：

- 哪一步最值得让它帮忙？哪一步您不希望交给AI？
- 什么信息必须显示，您才会相信？
- 它在什么情况下应该停止回答并建议找人工？
- 您愿不愿输入户籍类型、学生/就业状态、居住方式等非敏感情形？哪些问题让您不舒服？
- 如果只能保留三个功能，您选什么？

## 6. 结束

- 如果只能给上海青年公共服务提一条建议，您会说什么？
- 是否愿意后续参加原型测试？
- 再次确认匿名引用和影像授权范围。
