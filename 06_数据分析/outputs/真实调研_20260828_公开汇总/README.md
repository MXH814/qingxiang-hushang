# 真实调研脱敏聚合汇总

本目录只公开无法直接识别参与者的聚合结果和图表，不包含原始问卷、逐人任务记录、访谈全文、匿名引文库或联系方式。

## 数据范围

- 问卷：回收150份，按预设规则保留128份有效样本；
- 访谈：12人；
- 场景观察：2个服务点；
- 真人任务测试：12人、24次任务；
- 自动回归：50条程序用例，与真人样本分开报告。

## 使用边界

问卷采用便利抽样，校园与青年同伴渠道占比较高。结果用于识别本次样本中的高频问题、形成产品需求和开展探索性验证，不代表上海全部来沪青年。任务测试测量模拟办事准备，不等同于真实申请获批或政务系统办理效率。

公开统计由本地受限数据生成。为保护参与者，本仓库不提供从聚合结果反推逐人记录的复算入口。
