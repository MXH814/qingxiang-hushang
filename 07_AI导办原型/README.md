# 青享沪上导办原型

当前版本：`v0.4-research-driven`

## 运行

### 方式一：直接打开

双击 `prototype/index.html` 即可使用，无需安装依赖。

### 方式二：本地服务器（推荐）

在本目录打开终端并运行：

```powershell
python -m http.server 4174 -d "prototype"
```

然后访问 `http://127.0.0.1:4174/`。若系统没有 `python` 命令，也可使用任意静态网页服务器。

## 当前能力

- 根据自然语言关键词识别居住登记、居住证、租赁备案和青年安居需求；
- 通过情境选择区分市场租赁、自有/近亲属住房、单位/学校宿舍；
- 输出条件、材料、步骤、官方入口、更新时间和风险提示；
- 对青年驿站/保租房等动态信息拒绝直接作资格认定；
- 生成可打印的办事准备清单；
- 将结论、动态边界、来源所支持的具体判断和人工咨询兜底分层展示；
- 展示租赁备案、居住登记和居住证三项业务的前后关系；
- 不保存用户输入，不要求真实证件信息。

## 定位

这是用于社会实践需求验证和可用性测试的研究原型，不是政府服务，不代表最终办理资格。当前版本依据问卷、访谈、场景观察和配对任务测试反馈完成信息层级与人工兜底优化。

## 自动回归

在本目录运行：

```powershell
node "evaluate_engine.cjs"
```

回归结果写入 `评测结果_自动回归/`。当前门禁结果为50/50通过；该结果只验证规则路由、来源ID和风险边界，不等同于真人可用性测试。

## 发布门禁

- 核心政策知识经过两人核验；
- 所有关键结论有官方来源；
- 高风险评测集零严重错误；
- 动态政策在测试前再次更新；
- 页面明确展示非官方研究原型和隐私边界。
