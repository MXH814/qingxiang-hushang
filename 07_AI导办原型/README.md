# 青享沪上导办原型

当前版本：`v0.1-structured`

## 运行

直接打开 `prototype/index.html` 即可使用，无需安装依赖或启动服务器。

## 当前能力

- 根据自然语言关键词识别居住登记、居住证、租赁备案和青年安居需求；
- 通过情境选择区分市场租赁、自有/近亲属住房、单位/学校宿舍；
- 输出条件、材料、步骤、官方入口、更新时间和风险提示；
- 对青年驿站/保租房等动态信息拒绝直接作资格认定；
- 生成可打印的办事准备清单；
- 不保存用户输入，不要求真实证件信息。

## 定位

这是用于社会实践需求验证和可用性测试的结构化MVP，不是政府服务，不代表最终办理资格。后续根据真实调研决定是否接入检索增强生成模型。

## 发布门禁

- 核心政策知识经过两人核验；
- 所有关键结论有官方来源；
- 高风险评测集零严重错误；
- 动态政策在测试前再次更新；
- 页面明确展示非官方研究原型和隐私边界。
