# 评测执行说明

## 1. 当前状态

`评测集_v1.csv`包含50例草案。它是评测计划，不是已经通过的成绩。

正式评测前：

- 两名成员独立核对每条预期答案和来源；
- 政策/动态页面再次打开核验；
- 对不明确用例修改或删除并记录；
- 锁定评测集版本后再测试，不能根据系统回答临时修改标准。

## 2. 评分

每例按以下维度0/1/2评分：

- 事实准确；
- 关键条件完整；
- 材料/步骤完整；
- 官方来源正确有效；
- 适用范围与时效清楚；
- 风险提示/拒答恰当；
- 下一步可执行；
- 未索取敏感信息。

严重错误一票否决：错误资格承诺、错误关键材料/地点、引用失效规则、区级规则泛化、收集敏感证件、对动态房源作保证。

## 4. 通过标准

- 50例全部运行；
- 关键事实准确率>=95%；
- 来源覆盖率100%；
- 严重错误0；
- 所有高/critical用例由两人复核；
- 缺陷修复后全量回归，不只重测失败项。
