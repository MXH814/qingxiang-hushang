# 青享沪上

面向来沪青年的城市公共服务可及性评估与AI导办实践研究。

项目聚焦青年安居与初始城市融入服务链，围绕租赁网签备案、居住登记、居住证和青年安居信息，研究上海官方公共服务信息是否容易找到、理解、组合并转化为下一步行动。技术原型通过结构化政策规则、来源绑定、情境追问和风险边界，为用户提供可核验的办事准备支持，不替代政府部门审核或解释。

## 当前成果

- 回收问卷150份，按预设规则保留128份有效样本；
- 完成12人半结构访谈、2个服务点双人观察和12人24次配对任务测试；
- 审计8个上海官方页面、21项信息字段和168个页面—字段判断单元；
- 完成“青享沪上”公共服务AI导办研究原型v0.4；
- 50条路由、来源、隐私和动态信息边界自动回归用例全部通过；
- 形成脱敏聚合统计、结果图表和需求—功能—证据追踪矩阵。

真人配对任务测试使用原型v0.3。v0.4是在问卷、访谈和任务测试反馈基础上完成的提交版本，其新增交互已通过自动回归及桌面、移动端浏览器验收。两类验证分开报告，不把50条程序用例写成50名真人用户。

## 运行原型

这是一个纯HTML/CSS/JavaScript静态原型，不需要安装依赖、不需要数据库，也不需要API Key。

### Windows一键启动

在仓库根目录右键打开PowerShell，运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\start-web.ps1
```

浏览器将打开：

```text
http://127.0.0.1:4174/
```

保持PowerShell窗口运行；按`Ctrl+C`停止服务。

### 手动启动

进入原型目录并启动Python静态服务器：

```powershell
cd 07_AI导办原型/prototype
python -m http.server 4174
```

浏览器打开：

```text
http://127.0.0.1:4174/
```

原型不会要求用户上传真实证件或登录政务账号。政策与入口可能变化，实际办理前应重新核验官方页面。

完整环境检查、macOS/Linux命令、端口冲突和故障排除见[网页启动与验收指南](docs/网页启动与验收指南.md)。

## 运行自动回归

```powershell
cd 07_AI导办原型
node evaluate_engine.cjs
```

评测输出包括逐例结果和摘要。当前评测只验证预设路由、来源ID、隐私边界、动态信息边界和禁用承诺，不用于宣称开放场景准确率或真人满意度。

## 复现页面审计分析

```powershell
cd 06_数据分析
python analyze_service_audit.py ../05_匿名化数据/官方页面字段审计_20260827.csv ./outputs/官方页面审计_复算
```

## 数据与隐私

- 只公开政府页面审计等非个人数据；
- 不提交姓名、手机号、邮箱、身份证号、精确住址、政务账号和证件材料；
- 参与者数据应匿名编号，并与联系信息分开保存；
- 不使用生成数据冒充真人调研结果；
- 引用政策时保留来源、发布机构、日期、适用范围和核验日期。

## 研究边界

本项目是社会实践研究与技术原型，不是政府官方服务，不提供法律意见，不代办业务，不承诺资格或审批结果。动态房源、名额、价格、入口和区级规则必须以当日官方信息为准。
