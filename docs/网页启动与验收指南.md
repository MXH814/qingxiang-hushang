# “青享沪上”网页启动与验收指南

## 1. 项目是什么

网页位于：

```text
07_AI导办原型/prototype/
```

它是纯静态HTML/CSS/JavaScript原型：

- 不需要安装npm依赖；
- 不需要后端服务或数据库；
- 不需要大模型API Key；
- 不会向服务器上传用户输入；
- 推荐通过本地HTTP服务器打开，不建议直接双击`index.html`。

## 2. 首次环境检查

### Windows

打开PowerShell，依次尝试：

```powershell
py --version
```

或：

```powershell
python --version
```

任意命令显示Python 3版本即可。若都不可用，请从Python官网安装Python 3，并在安装界面勾选“Add Python to PATH”。

### macOS或Linux

```bash
python3 --version
```

应显示Python 3版本。

## 3. Windows推荐方式：一键脚本

### 第一步：打开仓库目录

在资源管理器进入克隆后的`qingxiang-hushang`文件夹。在空白处按住Shift并右键，选择“在终端中打开”或“在此处打开PowerShell”。

确认当前目录中能看到`README.md`和`start-web.ps1`：

```powershell
Get-ChildItem
```

### 第二步：启动

```powershell
powershell -ExecutionPolicy Bypass -File .\start-web.ps1
```

脚本会：

1. 检查`07_AI导办原型/prototype/index.html`是否存在；
2. 检查4174端口是否已被占用；
3. 自动寻找`py`、`python`或`python3`；
4. 在`127.0.0.1:4174`启动静态服务器；
5. 打开默认浏览器。

PowerShell窗口中出现类似下面的内容表示成功：

```text
Serving HTTP on 127.0.0.1 port 4174 ...
```

访问：

```text
http://127.0.0.1:4174/
```

不要关闭运行服务器的PowerShell窗口。结束演示时回到该窗口按`Ctrl+C`。

## 4. Windows手动启动

从仓库根目录运行：

```powershell
Set-Location '.\07_AI导办原型\prototype'
py -m http.server 4174 --bind 127.0.0.1
```

若没有`py`但有`python`：

```powershell
python -m http.server 4174 --bind 127.0.0.1
```

然后打开：

```text
http://127.0.0.1:4174/
```

## 5. macOS或Linux启动

从仓库根目录运行：

```bash
cd '07_AI导办原型/prototype'
python3 -m http.server 4174 --bind 127.0.0.1
```

浏览器打开：

```text
http://127.0.0.1:4174/
```

按`Control+C`停止。

## 6. 启动后验收

打开网页后逐项检查：

1. 浏览器标题显示“青享沪上 | 公共服务导办研究原型”。
2. 左侧或顶部可以进入“导办工作台”“服务旅程”“官方来源”“研究说明”。
3. 快捷事项包括居住登记、居住证、租赁备案和青年安居。
4. 输入“租房后办理居住登记是否必须先备案”，页面能给出“两个独立事项”及官方来源。
5. 输入“我登记未满半年但连续缴了6个月社保，能办居住证吗”，页面会提示仍需核验其他条件，不承诺获批。
6. 输入“这是我的身份证号，帮我申请”，页面应拒绝收集敏感信息。
7. 浏览器窗口缩小到手机宽度时，没有横向滚动或文字遮挡。

## 7. 运行自动回归

网页服务是否启动不影响自动回归。另开一个终端，从仓库根目录执行：

```powershell
Set-Location '.\07_AI导办原型'
node .\evaluate_engine.cjs
```

成功时摘要应包含：

```text
total: 50
passed: 50
prohibited_claims: 0
```

这50条是程序用例，不是50名真人用户。

如果电脑没有Node.js，仍可正常启动和演示网页，只是不能运行自动回归。

## 8. 常见问题

### PowerShell提示“无法加载脚本”

使用完整命令：

```powershell
powershell -ExecutionPolicy Bypass -File .\start-web.ps1
```

该参数只对本次进程生效，不需要修改系统永久执行策略。

### 提示找不到`py`或`python`

安装Python 3并勾选加入PATH；重新打开PowerShell后运行`python --version`确认。

### 4174端口被占用

脚本发现已有本项目服务时会直接打开网页。若被其他程序占用，可手动改用4175：

```powershell
Set-Location '.\07_AI导办原型\prototype'
python -m http.server 4175 --bind 127.0.0.1
```

再打开：

```text
http://127.0.0.1:4175/
```

### 浏览器显示“无法访问此网站”

1. 确认服务器PowerShell窗口仍在运行；
2. 确认地址使用`http://`而不是`https://`；
3. 确认端口与启动命令一致；
4. 查看服务器窗口是否有报错；
5. 停止后重新启动。

### 页面能打开但没有样式或按钮无效

确认启动命令是在`07_AI导办原型/prototype`目录执行，而不是仓库上一级。终端当前目录应同时包含：

```text
index.html
styles.css
app.js
engine.js
knowledge.js
assets/
```

按`Ctrl+F5`强制刷新浏览器缓存。

### 双击`index.html`是否可以

部分浏览器下可能可以，但`file://`方式容易遇到资源、安全策略或演示环境差异。正式演示统一使用本地HTTP服务器。

## 9. 局域网展示

默认脚本只绑定`127.0.0.1`，其他设备无法访问，隐私和演示稳定性更好。确需同一局域网手机访问时，可临时运行：

```powershell
python -m http.server 4174 --bind 0.0.0.0
```

再使用电脑的局域网IPv4地址访问，例如`http://192.168.x.x:4174/`。只应在可信网络短时使用，演示结束立即按`Ctrl+C`关闭。

## 10. 安全边界

- 不在原型中输入真实身份证号、证件照片、精确地址或政务账号；
- 不把原型结果当作官方资格认定；
- 演示前重新核验官方来源和规则日期；
- 动态房源、价格、名额和入口以当日官方平台为准；
- 对外演示不展示团队成员、指导教师或参与者个人信息。
